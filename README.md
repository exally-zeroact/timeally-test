# Timeally（タイマリー）

**タイムカード。** time + ally。合同会社ZEROact。

打刻の生データは **1分単位で残す（丸めない・上書きしない・消さない）**。
会社が選べるのは**見せ方**だけで、原本は動きません。

---

## 誰が何を見るか

| 誰 | 画面 | 見える物 |
|---|---|---|
| 従業員 | `punch.html?t=…` | **打つだけ**（出勤／退勤／休憩／私用で外出） |
| 従業員 | `kiroku.html?t=…` | **自分が打った1分単位の生の時刻だけ** |
| 社長 | `index.html` | 直しのお願い（未承認が上）／従業員の入口／会社情報 |
| 社長 | `shukei.html` | 日ごと・月計・気づき・印刷・CSV・Excel |
| 社長 | `login.html` | 会社の入口（自前のログイン） |

**従業員の画面には、数えた結果（働いた長さ・残業・丸め・金額・法律の話）を1つも出しません。**
だから **従業員は嘘の数字を一度も見ません。** 記録は社長側と帳簿に必ず残します。

---

## 従業員の入口（リンク＋あいことば）

1. 社長が「従業員」タブで人を追加 → **リンク（QRも出せる）** と **最初のあいことば** ができる
2. 従業員がリンクを開き、最初のあいことばを入れて **自分のあいことば（8文字以上）** を決める
3. 以降は **その端末を覚える**ので聞きません（「この端末を忘れる」で解除）
4. **5回まちがえると15分あきません。** あいことばは平文で持ちません（bcrypt）

---

## 時間の見せ方（会社情報で選ぶ）

| 選ぶ物 | 中身 | 法律 |
|---|---|---|
| `none`（既定） | 1分単位のまま | **適法** |
| `month` | 1か月合計の時間外・休日・深夜の端数だけ（30分未満切捨／30分以上切上） | **適法**（昭和63.3.14 基発150号） |
| `daily30` | 日ごとに30分へ切り下げ | **適法ではない**（労基法24条） |

**`daily30` を選んだ場合は、切り捨てた時間と金額を集計画面に必ず出します。**
（他社は丸めて終わり。うちは「丸めた分がいくらか」を出せます）

法定の数値はすべて `lib/tc-law.js` に **出典URL＋確認日つき**で1か所に置いています。

## 給与へ渡す

`shukei.html` の「給与へ渡す（全員・CSV）」で、給与アプリの受け口
（`exally-prod/kyuyo/lib/kintai-csv.js`）が読める形の CSV を出します。

**合格条件は1行**：出したCSVを `kintai-csv.js` に食わせて rows が期待どおり。
`tests/tc-csv.test.mjs` が**受け取る側の本物を実際に走らせて**確かめています
（＝繋ぐ前にテストだけで確かめられる）。

## 開発

```
npm install
node tests/run.js               # 全部（自己確認込み）
node scripts/stamp-build.mjs    # ?v= を貼り直す
npm run db:apply                # 倉庫に設計図を当てる（門番を必ず通る）
```

決まりは `CLAUDE.md`。借りてきた物は `VENDOR.md`。
